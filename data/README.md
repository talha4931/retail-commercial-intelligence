# Data

The Online Retail II source workbook is not committed to this repository.

Download it from the [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/502/online+retail+ii) and place the original workbook in data/raw/ before running the preparation workflow.

Do not commit the raw workbook, customer-level exports or other potentially sensitive/high-volume intermediate data. The preparation workflow and expected output locations will be documented with the scripts.

The UCI dataset is licensed under CC BY 4.0. Retain attribution to the original source.
